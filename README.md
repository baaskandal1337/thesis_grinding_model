# thesis_grinding_model

Steady-state model of grinding/classification node.

## How to run
1. Create venv: `python -m venv .venv`
2. Activate: `.\.venv\Scripts\Activate.ps1`
3. Install deps: `pip install -r requirements.txt`
4. Open `notebooks/01_base_case.ipynb` in VS Code and select kernel from `.venv`, then Run All.
